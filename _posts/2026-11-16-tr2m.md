## Introduction

항상 모든 논문에서 말하지만, MDE는 여러 분야에 핵심적인 과제이다. MDE는 크게 두 가지로 나눌 수 있다.

- **Monocular metric depth estimation (MMDE)**: 미터 단위로 depth를 예측. 출력 범위에 제한이 없어 scale이 다양한 test 데이터에서 성능이 크게 떨어지기 쉽고, 이를 고치려고 camera 정보나 scene 정보 같은 추가 조건을 쓴다.
- **Monocular relative depth estimation (MRDE)**: 통일된 scale로 depth를 예측. Affine-invariant loss 덕분에 대규모 데이터로 학습할 수 있어 domain을 가리지 않고 일반화가 좋다. 하지만 scale을 모르므로 로봇 경로 계획·navigation처럼 실제 scale이 필요한 곳에 쓰기 어렵다.

본 논문의 목표는 **relative depth의 scale 불확실성을 풀어, MRDE만큼 일반화가 좋은 MMDE pipeline**을 효율적으로 만드는 것이다. 단서로는 text description을 쓴다. 장면에 있는 물체로 scene scale을 짐작할 수 있기 때문이다 (예: 차나 집이 보이면 실외라 scale이 크다). 이는 RSA가 먼저 보였다.

큰 방법론은 다음과 같다.

1. 이미지와 text description에서 각각 frozen encoder로 feature를 뽑는다. 이미지는 DINO, 텍스트는 CLIP 기반 인코더를 사용한다.
2. Cross-modality attention이 있는 가벼운 network가 두 feature를 받아 **scale map과 shift map**을 예측한다.
3. 두 map으로 relative depth를 픽셀별 선형 변환해 metric depth를 얻고, GT metric depth로 supervision한다.
4. GT가 없는 영역까지 학습하도록, relative depth를 GT에 맞춘 pseudo metric depth 중 믿을 만한 것만 추가 supervision으로 쓴다.
5. 같은 depth scale을 가진 feature끼리 일관되도록 Dual-Level Scale-Oriented Contrast를 건다.

\[문제점1\]<br>
SOTA relative depth 모델에도 넓게 틀린 영역이 여전히 있다. 기존 language 기반 방법(RSA)처럼 **이미지 전체에 scale·shift factor 하나씩만 적용하면, 이 오류가 그대로 남거나 오히려 커진다**.

\[해결책1\]<br>
숫자 2개 대신 픽셀마다 다른 값을 갖는 **rescale map 2장**(scale map, shift map)을 예측해 픽셀 단위로 고친다. ⇒ 픽셀별로 보정해주자!

\[문제점2\]<br>
같은 물체라도 분포와 비율이 다르면 전체 depth가 달라지지만, text description은 같거나 매우 비슷할 수 있다. **텍스트만으로는 scale이 모호하다**.

\[해결책2\]<br>
**이미지와 텍스트를 함께 입력**으로 쓰고, cross-modality attention으로 두 feature를 합친다. ⇒ Scale에 대한 knowledge는 text와 image의 cross attention으로 얻을 수 있다.

\[문제점3\]<br>
Feature 수준의 scale 일관성은 흔히 간과된다. Depth와 scale이 비슷한 픽셀인데도 **pixel-level feature 유사도가 낮을 수 있어**, 전체 depth 추정이 불안정해진다.

\[해결책3\]<br>
**Dual-Level Scale-Oriented Contrast**: 이미지 단위로는 scene scale이 비슷한 이미지끼리, 픽셀 단위로는 depth 구간이 같은 픽셀끼리 feature를 가깝게 하고 다르면 멀게 한다.

Contribution은 다음과 같다.

- 이미지와 text description으로 rescale map을 예측해, 여러 domain에서 relative depth map을 metric depth map으로 옮기는 framework를 제안한다.
- Depth를 분포에 따라 class로 나눠 global scale consistency를 강제하는 Dual-Level Scale-Oriented Contrast Learning을 제안한다.
- 여러 scene의 실험으로 성능을 확인한다. 저자들이 아는 한 text description으로 relative → metric depth를 픽셀 단위로 변환한 첫 연구이다.

## TR2M

![TR2M framework](fig2.webp)
_출처: 원 논문 Figure 2_

### 1. Overview

1. RGB 이미지 $$I \in \mathbb{R}^{H\times W\times 3}$$와 text description $$L$$을 받아 scale map $$A \in \mathbb{R}^{H\times W}$$와 shift map $$B \in \mathbb{R}^{H\times W}$$를 추정한다.
2. 이 두 map으로 pre-trained relative depth 모델의 출력 $$D_r$$을 metric depth $$\hat{D}_m$$으로 rescale한다.
3. \\(\hat{D}_m\\)은 GT $$D^{gt}_m$$으로 학습하고, $$D_r$$을 $$D^{gt}_m$$에 linear regression으로 맞춘 pseudo metric depth $$D^{pseudo}_m$$이 충분히 좋으면 그것도 supervision으로 쓴다. 여기에 scale perception을 높이는 dual-level scale-oriented contrast를 더한다.

### 2. Scale and Shift Map Estimation

**Network architecture.** 이미지와 텍스트 모두 scale 단서를 주지만, 한 modality만으로는 전체 layout이나 평균 scale을 놓쳐 모호하다. 그래서 둘을 함께 쓴다. Frozen image encoder(DINOv2 ViT-L)로 image feature $$F_I \in \mathbb{R}^{HW\times D}$$를, frozen text encoder(CLIP ViT-L/14)로 text feature $$F_L \in \mathbb{R}^{1\times D}$$를 뽑는다.

Cross-modality attention에서는 픽셀 단위 출력을 유지하도록 **image feature를 query로** 두고, image feature와 text feature에서 각각 key·value를 가져온다.

$$
\mathrm{Attn}^{i}_{cm}(Q_I, K_i, V_i) = \mathrm{softmax}\left(\frac{Q_I K_i^T}{\sqrt{d}}\right) V_i, \quad i \in \{I, L\}
$$

$$
F_{out} = F_I + \mathrm{Attn}^{I}_{cm} + \mathrm{Attn}^{L}_{cm}
$$

쉽게 말해, image feature가 self-attention으로 자기 자신을, cross-attention으로 텍스트를 보고 모은 정보를 skip connection으로 더한다.

DPT 방식의 가벼운 decoder head 두 개가 fine scale map $$A = \mathrm{Scale_{head}}(F_f)$$와 fine shift map $$B = \mathrm{Shift_{head}}(F_f)$$를 만든다. Frozen relative depth 모델(Depth Anything-Small)이 만든 $$D_r$$은 다음과 같이 rescale한다.

$$
\hat{D}_m = \frac{1}{A \odot D_r + B}
$$

$$\odot$$은 픽셀별 곱이다. 픽셀마다 scale·shift를 따로 적용한 뒤 역수를 취한다 (Figure 2의 $$D^{-1}$$, Reciprocal Transformation). Depth Anything의 출력이 depth의 역수(disparity) 꼴이기 때문이다. 학습에는 Scale-Invariant log loss를 쓴다.

$$
\mathcal{L}_{si}(\hat{D}_m, D^{gt}_m) = \frac{1}{HW}\sum_{i=1}^{HW}\epsilon_i^2 - \frac{\lambda}{(HW)^2}\left(\sum_{i=1}^{HW}\epsilon_i\right)^2
$$

**Pseudo metric depth with threshold.** GT metric depth는 sparse해서 일부 픽셀은 scale을 배울 supervision이 없다. 그래서 relative depth를 GT에 least-squares로 맞춘 pseudo metric depth를 쓴다. 이미지 하나에 scale $$\tilde{\alpha}$$와 shift $$\tilde{\beta}$$를 하나씩 구한다.

$$
(\tilde{\alpha}, \tilde{\beta}) = \arg\min_{\tilde{\alpha}, \tilde{\beta}} \sum_{i=1}^{HW}\left(\tilde{\alpha} D_r(i) + \tilde{\beta} - D^{gt}_m(i)\right)^2
$$

$$D^{pseudo}_m = \tilde{\alpha} D_r + \tilde{\beta}$$이며 closed form으로 풀린다. 이 pseudo depth의 $$\delta_1$$ ($$\max(D^{gt}_m/D^{pseudo}_m, D^{pseudo}_m/D^{gt}_m) < 1.25$$인 픽셀 비율)이 threshold $$\rho$$보다 클 때만 supervision으로 쓴다.

$$
\mathcal{L}_{tp-si}(\hat{D}_m, D^{pseudo}_m) = \mathbb{1}(\delta_1 > \rho)\cdot\mathcal{L}_{si}(\hat{D}_m, D^{pseudo}_m)
$$

보충 설명: 픽셀별 보정맵을 만들고 싶은데, 라벨 이미지는 정답이 희소하게 존재한다. 따라서 pseudo-label과 GT label이 해당 픽셀에서 어느 정도 일치하면 **GT에 없는 픽셀을 pseudo-label을 통해 학습**한다.

### 3. Dual-Level Scale-Oriented Contrast

![Dual-level scale-oriented contrast](fig3.webp){: w="480" }
_출처: 원 논문 Figure 3_

**Image-level coarse contrast.** 이미지 한 장을 feature 벡터 하나로 요약하고($$F_f$$를 average pooling한 $$\tilde{F}_f$$), 장면 scale이 비슷한 이미지끼리 이 벡터가 가까워지도록 한다. 장면 scale의 기준으로는 앞에서 pseudo depth를 만들 때 구한 scale factor $$\tilde{\alpha}$$를 쓴다. 한 iteration에서 고른 이미지 $$M$$장을 $$\tilde{\alpha}$$ 크기 순으로 줄 세운 뒤, 순위 차이가 $$t$$보다 작은 쌍($$\lvert i-j\rvert < t$$)은 positive(가깝게), 그 외는 negative(멀게)로 둔다.

$$
\mathcal{L}_{coarse} = -\frac{1}{M}\sum_{i=0}^{M-1}\log\frac{\exp(S^{c-p}_i)}{\exp(S^{c-p}_i) + \exp(S^{c-n}_i)}
$$

$$
S^{c-p}_i = \frac{1}{\lvert\mathbf{F}\rvert}\sum_{F_1, F_2 \in \mathbf{F}}\sum_{\lvert i-j\rvert<t}\langle F^i_1 \cdot F^j_2\rangle, \qquad S^{c-n}_i = \frac{1}{\lvert\mathbf{F}\rvert(M-1)}\sum_{F_1, F_2 \in \mathbf{F}}\sum_{\lvert i-j\rvert\ge t}\langle F^i_1 \cdot F^j_2\rangle
$$

$$S^{c-p}_i$$는 이미지 $$i$$와 positive 이미지들 사이의 평균 유사도, $$S^{c-n}_i$$는 negative 이미지들과의 평균 유사도이다 ($$\langle\cdot\rangle$$ = cosine similarity). $$t$$는 순위가 몇 칸 차이까지를 '비슷한 scale'로 볼지 정하는 값이다.

단순하게 말하면, **장면마다 스케일이 비슷한 이미지끼리 feature가 모이게** 한다.

Why? DINOv2 같은 semantic encoder는 **깊이가 다른 영역에도 비슷한 feature**를 내는 경우가 많다 (예: 차의 앞과 뒤). 깊이 추정은 이를 분리할 수 있어야 하기 때문.

**Pixel-level fine contrast.** 이번에는 픽셀 단위로, depth가 비슷한 픽셀끼리 feature가 가까워지게 한다. 먼저 GT depth map의 범위를 $$C$$개 구간으로 나눠, 픽셀마다 몇 번째 구간에 속하는지 class 번호를 붙인다.

$$
Y = \mathrm{round}\left(\frac{d_{max} - D}{d_{max} - d_{min}} \times \lvert C\rvert\right)
$$

$$d_{min}$$, $$d_{max}$$는 그 depth map의 최솟값·최댓값이다. 이 class map을 feature 해상도에 맞게 줄인 뒤, query 이미지의 픽셀 $$i$$를 key 이미지들의 픽셀과 비교해 **같은 구간이면 positive, 다른 구간이면 negative**로 둔다.

$$
\mathcal{L}_{fine} = -\frac{1}{hw}\sum_{i=1}^{hw}\log\frac{\exp(S^{f-p}_i)}{\exp(S^{f-p}_i) + \exp(S^{f-n}_i)}
$$

$$S^{f-p}_i$$는 query 픽셀 $$i$$와 같은 구간에 있는 key 픽셀들과의 평균 cosine similarity, $$S^{f-n}_i$$는 다른 구간 픽셀들과의 유사도이다. 식 모양은 image-level과 같고 비교 단위만 이미지에서 픽셀로 바뀌었다. 최종 scale-oriented loss는 $$\mathcal{L}_{soc} = \mathcal{L}_{coarse} + \mathcal{L}_{fine}$$이다.

분자에는 positive 쌍의 유사도, 분모에는 positive와 negative 유사도가 함께 들어가므로, loss를 줄이려면 비슷한 scale·depth끼리는 가까워지고 다른 것끼리는 멀어져야 한다. 그 결과 feature가 **'무슨 물체인가'보다 '얼마나 먼가'를 기준으로** 모인다.

### 4. Training Strategies

위 loss에 scale·shift map을 매끄럽게 만드는 edge-aware smoothness loss $$\mathcal{L}_{es}$$ (Godard et al.)를 더해 end-to-end로 학습한다.

$$
\mathcal{L} = \lambda_1\mathcal{L}_{si} + \lambda_2\mathcal{L}_{tp-si} + \lambda_3\mathcal{L}_{soc} + \lambda_4\mathcal{L}_{es}
$$

- \\(\mathcal{L}_{si}\\): GT 정답 ($$\lambda_1 = 1$$)
- \\(\mathcal{L}_{tp-si}\\): Pseudo 정답 ($$\lambda_2 = 0.5$$)
- \\(\mathcal{L}_{soc}\\): feature 정렬 ($$\lambda_3 = 0.1$$)
- \\(\mathcal{L}_{es}\\): map 매끄럽게 ($$\lambda_4 = 0.01$$)

- 자세한 실험 설정은 논문 참고
- 학습: NYUv2, KITTI, VOID, C3VD (실내·실외·수술 장면)를 모델 하나로 함께 학습 (102K장). Text description은 RSA를 따라 LLaVA v1.6으로 생성.

## Conclusion

본 논문은 monocular relative depth를 metric depth로 옮기는 일반화 가능한 framework TR2M을 제안함. Text description과 이미지를 받아 픽셀 단위 변환을 위한 **rescale map 2장**을 예측하고, cross-modality attention으로 두 modality의 feature를 합친다. Relative depth를 GT에 맞춘 pseudo metric depth 중 믿을 만한 것을 supervision으로 쓰고, depth 분포를 모델링하는 scale-oriented contrastive learning으로 scale perception을 높였다. 가벼운 network 하나로 여러 domain에서 강한 zero-shot metric depth 성능을 보인다.

**장점**

- 숫자 2개 → 지도 2장: 단순한데 효과가 가장 크다 (NYUv2 AbsRel 0.118 → 0.084).
- 학습 19M·102K장, 모델 하나로 여러 domain을 함께 학습.
- Zero-shot 평균 순위 1위 (2.40), KITTI에서는 GT로 이미지마다 맞춘 것보다도 좋다.

**질문 (개인 해석)**

- 텍스트는 정말 도움이 되나? 이미지만 0.085 vs 둘 다 0.082인데, 추론할 때마다 LLaVA로 설명을 만들어야 한다.
- 정말 작은 모델인가? 학습 파라미터는 19M이지만 추론에는 DINOv2-L + CLIP-L + Depth Anything-S가 모두 필요하다.
- Rescale 식과 pseudo depth 식은 같은 공간인가? $$\hat{D}_m$$은 $$A \odot D_r + B$$의 역수라 역수 공간에서 맞추는데, pseudo depth는 $$\tilde{\alpha} D_r + \tilde{\beta}$$를 GT depth에 직접 맞춘다 (depth 공간). Supplementary 확인 필요.
